# Engineering Practice

A repository for learning engineering concepts through implementation.

## Goals

- Implement concepts directly.

- Compare the same idea across languages when useful.

- Keep practice code separate from larger experiments and projects.

## Structure

- `dsa` — Data structures and algorithms

- `concurrency` — Threads and synchronization

- `os` — Operating system concepts

- `network` — Networking

- `storage` — Storage and databases

Language-specific implementations live inside each topic.

## Languages

- C++

- Java

- Go

- Python
